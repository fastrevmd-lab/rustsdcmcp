## Summary

Fixed error message attribution bug where `apply_sdc_change_set` validation of `expected_preview_digest` incorrectly blamed `expected_digest` in the error message.

### Root Cause

Line 110 in `crates/rustsdcmcp-core/src/change.rs` returned error message "prepared action does not match the approved preview digest" when the `expected_preview_digest` parameter didn't match. The mecmcp-changeset coordinator adds field prefixes to errors, but the message text suggested the wrong binding, leading operators to debug `expected_digest` instead of `expected_preview_digest`.

### Fix

1. Changed error message to "apply input does not match the previewed effect" — clearer language that describes the preview digest binding without suggesting it's about the plan digest
2. Added test `wrong_expected_preview_digest_names_the_right_field` that:
   - Creates a transaction with a deliberately wrong `expected_preview_digest`
   - Asserts the error message is exactly "apply input does not match the previewed effect"
   - Documents that this is the preview digest check, not the plan digest check
